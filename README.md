Emberfall — Duel of the Last Ember: an original turn-based card duel against the Ash Warden. Both keepers hold 24 Ember; play Flame cards to strike, Stone to guard, Bloom to mend, and Gale to storm and draw. Each round you gain mana and draw a card, block soaks damage, and an empty deck burns you. The Warden reads the table — it takes lethal when it sees it, shields when it is bleeding, and heals when it is low — so every hand is a decision. Keyboard and mouse, offline, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
